Sync agents

Run plan_then_apply_agents_safe_controlled against the configured checkout. Writes to the selected harness's destination paths, not the source checkout. Safe sync can remove unchanged owned targets whose source was removed. Refuses while the editor is open. Cancel is cooperative — no force-kill.

Install skills

Run plan_then_apply_skills_controlled against the configured checkout's skills/ sibling. OpenCode-only; refuses while the editor is open. Installation can remove unchanged owned skills whose source was removed. Cancel is cooperative.
