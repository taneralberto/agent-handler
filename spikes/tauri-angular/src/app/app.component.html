agenthd GUI

Settings + Agents view backed by the agenthd library. Two read-only commands (settings_status, list_agents) and one mutating command (apply_checkout) — all routed through the lib's pure composition helpers. Refresh is manual; the Save button persists the typed checkout path through the same workflow the TUI Settings screen uses.
